# Ouro Next (iPhone app)

Expo SDK 58. `ios/` is generated by `expo prebuild` and is not committed; `app.json` is the source for all native settings.

Native dependencies and `app.json` native settings need a new TestFlight build. Bump `version` when they change: the
runtime version follows it (`runtimeVersion.policy: appVersion`), which keeps live updates from reaching a binary that
can't run them.

`updates.url` is a deliberately unresolvable placeholder. The native library needs a URL at launch, and each person's
server supplies the real one at run time through `setUpdateURLAndRequestHeadersOverride`, which is why
`disableAntiBrickingMeasures` is on.
